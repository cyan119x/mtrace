# Historical source reference, not runnable packages

These selected snapshots document the path from core changes to the independent MTrace Feature Plugin. They are added now as source artifacts, not backdated Git history. The existing reconstructed commits already preserve the plugin 0.1.0, 0.1.1, 0.1.2, 0.2.0 and 0.2.1 code. Exact matching files are mapped to commit:path rather than duplicated.

SOURCE_MAP.json records original source SHA-256, retained locations, duplicates and transformations. The dated labels describe discovery provenance, not verified original authorship or release dates. Where an old file differs, the meaningful source is retained here. This is a sparse reference collection: relative imports and package scripts may require missing files or the original pinned upstream checkout. Do not install, build or execute it as a workspace. Files with /path/to/ values are explicitly non-operational archival placeholders.

## Privacy and rights
Actual transcripts, full/history/prompt-tool-runtime downloads, private validation, native captures, credentials and machine state are excluded without payload inspection. Historical reports and private project notes are not copied verbatim; only project-level decisions are summarized. Mock fixtures are code-generated or explicitly mocked; a historical mock UUID was normalized, with mapping. Synthetic secret strings test redaction and are not credentials.

Existing root LICENSE and THIRD-PARTY-LICENSES.md are unchanged. OPENCLAW-LICENSE and the root THIRD_PARTY_NOTICES.md are exact notices from the historical upstream staging archive, including Pi and Octicons notices. Core snapshots derive from that OpenClaw lineage; their full original baseline is not independently reconstructed here. No new third-party grant is asserted. No external media assets were found in the selected source set; CSS and source-rendered UI remain included.
